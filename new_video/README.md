## 3. 자막·사운드 및 제작 순서

- **자막 2단 분리**: 하단 중앙은 내레이션 자막(최대 2줄, 흰색 산세리프)만 배치하고, 연도·출처는 좌측 상단 미니 캡션(1줄)으로 분리합니다. 전체 AI 재현 고지는 S16 엔딩 카드 하단에 1회 통합합니다.
- **음악**: 미니멀 피아노 + 따뜻한 첼로/현악 + 은은한 자연음(파도·바람). 수난(S04–S05)은 낮은 첼로 지속음, 엔딩(S16)은 밝고 절제된 화음.
- **권장 진행 순서**: 1) 내레이션 음성 먼저 제작 및 실측 → 2) 16숏 키프레임 이미지 생성 → 3) I2V 생성(불안정 컷은 켄 번즈 팬/줌 대체) → 4) 자막·음악 최종 합성. (실제 생전 사진을 넣고 싶다면 본편 중간이 아닌 S16 이후 5초 독립 에필로그 카드에만 배치 권장)
