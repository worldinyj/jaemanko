# 고재만과 고성 숭의원 사료조사

고재만(高在萬)의 고려신학교 학적, 당동교회와 숭의원교회 개척, 고성 숭의원의 운영 경위를 조사한 자료다. 2026년 11월 27일까지 확인한 당대 신문, 관보, 기관 소장 목록과 가족 아카이브의 공개 자료를 바탕으로 작성했다.

## 현재 확인 범위

- 1957년 8월 31일 『부산일보』는 경남도 집계를 인용해 ‘고성 숭의원(固城 崇義園) 483명’을 보도했다. 같은 해 9월의 기사 세 건은 동해면 감서리 수용소의 설치 시기를 1951년으로 적었다. [『부산일보』 3면](https://www.busan.com/view/busan/view.php?code=19570831000026) · [『마산일보』 2면](https://www.nl.go.kr/newspaper/detail.do?content_id=CNTS-00113012801)
- 1959년 관보는 박만석을 재단법인 설립자·이사장, 고재만을 감사로 적었다. 1960년 『마산일보』는 전도사 고재만이 이사장으로 추대됐다고 보도했다. [1959년 관보 제2300호 6쪽](https://theme.archives.go.kr/viewer/common/archWebViewer.do?singleData=N&archiveEventId=0027983020) · [1960년 『마산일보』 2면](https://www.nl.go.kr/newspaper/detail.do?content_id=CNTS-00113046990)
- 고려신학대학원의 제9회(1955) 동창회 명단에 고재만이 기재돼 있다. 1956년 7월 23일 시설 허가의 원본과 명의, 두 교회의 개척자와 당시 소속을 보여주는 노회 원문은 추가 확인 대상이다. [공식 동창회 명단](https://www.kts.ac.kr/home/el_name/10?page=5) · [국가기록원 시설허가 신청 기록](https://www.archives.go.kr/next/newsearch/showDetailPopup.do?rc_code=1310377&rc_rfile_no=200301028151&rc_ritem_no=000000000005&sitePage=0-0-0)

가족 사진과 사료 원본은 별도 보관한다. 이 폴더에서 공개 출처와 원문 위치를 찾아볼 수 있다. 영상 제작에 쓰이는 자료는 [영상 프로젝트의 사료 검증 문서](../film/02_archive/FACT_REGISTER.md)에서 확인할 수 있다.
