## 공개 저장소 운영 원칙
이 저장소는 공개 상태이다. 제적등본, 학적부 전체, 사적 녹취, 가족 개인정보, 비공개 사진, 외부 서비스 토큰은 커밋하지 않는다. 사진과 사료 원본은 승인된 별도 보관소에 저장하고, 공개 가능한 파생물과 메타데이터만 검토 후 게시한다. 실제 웹사이트 코드·배포 작업과 영상 제작 작업은 분리한다.

V2.0은 기존 복고풍 수채화 기획 V1.0~V1.1을 대체하는 제안이며 아직 이미지·영상 생성 및 공개 승인은 하지 않았다.
