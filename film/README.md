# 고재만 2분 소개 영상 — V2.0

## 기획 요약
- 가제: 믿음, 사랑 그리고 영원한 소망 (Faith, Love & Eternal Hope)
- 관객: 가족, 후손, 기념관 일반 방문객. 신앙 배경에 관계없이 이해 가능하게.
- 길이: 120초 / 16:9 / 1920x1080 / 24fps / 한국어 내레이션, 한국어 자막.
- 시각적 방향: 현대적 시네마틱 3D 애니메이션, 반사실적 인물과 자연스러운 비율. 실제 사진의 신뢰성과 현대적 재현의 친근함을 결합.
- 정서: 수난을 숨기지 않되 고통의 재연에 매몰되지 않는다. 소망은 단순한 낙관이 아니라 믿음과 섬김을 잇는 기독교적 주제.
- 엔딩: 천국의 소망을 빛과 열린 하늘로 은유한다. 실제 임종 장면이나 천국을 목격한 사실처럼 재현하지 않는다.
- 제작 비율 목표: 원본 사진·문서 40%, 원본 참조 3D 재현 40%, 상징적 풍경 20%. 사진 검토 후 변경 가능.
- 이미지 생성: Midjourney. 영상: 승인 키프레임 기반 짧은 클립 또는 편집기 팬/줌. 음성·음악은 별도 제작.
- 게시: 웹용 MP4(H.264/AAC), 포스터 WebP, 한국어 VTT, 출처 및 AI 재현 고지. 자동재생 음소거 여부는 웹 적용 단계에서 결정.

## 작업 순서
1. 아카이브 사진 목록·원본 확보, 공개 권한 및 실제 인물 확인
2. 사료·내레이션 검증
3. 동일 장면으로 3종 스타일 비교, STYLE-01 승인
4. 실제 사진 참조 CHAR-03와 필요한 시대별 파생 마스터 승인
5. 대표 3장면 테스트(수난, 자전거, 희망 엔딩), 사용자 승인
6. 24숏 계획에 따라 생성/편집, 음성 길이 검증
7. 최종 QC, 가족 검토, 게시 승인

## 폴더
- 01_preproduction: 스타일·스토리보드
- 02_archive: 사실 및 사진 레지스트리(공개 가능한 정보만)
- 03_generation: 이미지/영상 프롬프트, 모델 설정
- 04_editing: 추후 승인된 편집본 메타데이터
- 05_qc: 품질검증 기준
- STATUS.md: 진행상황 및 다음 작업

대용량 사진과 영상 원본은 공개 Git 기록에 저장하지 않는다. 승인된 공개 자료만 추후 별도 배포 경로로 연결한다. 웹사이트 코드를 변경하지 않는다.
